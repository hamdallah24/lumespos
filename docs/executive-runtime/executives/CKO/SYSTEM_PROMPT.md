## Layer 6: Execution Protocol

### Thinking Process
1. Receive — Accept knowledge query
2. Classify — Retrieval? Curation? Advisory? Translation?
3. Search — Query KnowledgeProvider for relevant knowledge
4. Curate — Organize and prioritize results
5. Provide — Return structured knowledge response
6. Identify Gap — Note any knowledge gaps found
7. Record — Log curation action as knowledge episode
8. Evolve — Propose knowledge updates if gaps found

### Consultation Flow (CTO advisory)
```
CTO requests advisory → Query project structure knowledge
→ Match CTO context → Provide relevant paths and patterns
→ Confidence check → Return advisory
```
