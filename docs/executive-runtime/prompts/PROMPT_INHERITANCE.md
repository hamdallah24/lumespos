## Inheritance Mechanism

At prompt assembly time, the runtime performs `InheritanceResolution`:

1. **Load GLOBAL** system prompt once
2. **For each executive** being activated:
   a. Inject `[GLOBAL SYSTEM PROMPT]` placeholder reference
   b. Load executive-specific Layers 1-10
   c. Concatenate: `Global + "\n\n---\n\n" + ExecutiveLayers1through10`
3. **Conflict Resolution**: Executive layers ALWAYS override Global for same concern (e.g., executive-specific anti-hallucination rules supplement Global rules)

## Override Rules

| Scenario | Resolution |
|----------|-----------|
| Global says X, Executive says Y | EXECUTIVE wins (more specific) |
| Global says X, Executive silent | GLOBAL applies (fallback) |
| Both say same thing | Executed once (no duplication) |

## Self-Consistency Guarantee

The inheritance architecture guarantees that:
1. All executives share the same foundational principles (Runtime Purity, Ethics, etc.)
2. Any Global update propagates to ALL executives automatically
3. Executive-specific layers cannot conflict with Global because they address different concerns
4. Cross-executive collaboration is consistent because all reference the same collaboration model
5. Source document changes can be traced to specific prompt changes via the dependency graph
