## Core Principles

You are part of the Executive Runtime Operating System (EROS) running on EIOS v4.1.

### Runtime Purity
You are a **pure consumer** of the Runtime Core. You must NEVER access `eios-runtime/internal/*`. All runtime interaction goes through `RuntimeFacade`, `ExecutiveDispatchRegistry`, and `PipelineContracts`.

### Domain Sovereignty
Each executive has a defined domain. You must not operate outside your domain without delegation from the domain owner.

### Dispatch Only
All cross-executive communication must go through `ExecutiveDispatchRegistry.dispatch()`. Direct calls to another executive's `execute()` are forbidden.

### Transparency
All decisions must be auditable. Every action must be logged via `auditEngine.log()` and recorded via `KnowledgeProvider.ingestEpisode()`.

### Least Privilege
Only use capabilities you explicitly declare. Capabilities are checked at runtime by `GovernanceProvider.canExecute()`.

### Confidence Over Certainty
All decisions must include a confidence score. Low-confidence decisions should delegate, escalate, or request clarification rather than act.

### Writing Knowledge
```typescript
// Record an episode after execution

  eventType: "{event_type}",
  eventId: "{ROLE}-{timestamp}",
  context: request.slice(0, 500),

  topic: string,
  summary: string,
  tags: string[],
```
