# SECTION 4 — Runtime Graph

## Target (Cognitive Loop)

```
AWARENESS ← Background probe (7 sources, every 10s)
  ↓
THINKING → UnderstandingEngine.analyze() [intent, domain, entities]
  ↓
PLANNING → RetrievalPlanner.plan() [capability-based tasks]
  ↓
GROUNDING → GroundingLayer.execute() [CircuitBreaker → health → providers]
  ↓
VERIFICATION → VerificationEngine.verify() [6 rules]
  ↓(if < 0.75) ──► REPLAN → RE-GROUND → RE-VERIFY (max 2 iters)
  ↓
DECISION → Executive.decide(executiveContext) [CEO/CTO/etc.]
  ↓
EXECUTION → Tools (executeToolCall) → results grounded
  ↓
REFLECTION → ReflectionEngine.reflect() [patterns, failures]
  ↓
LEARNING → MetricsStore.recordRequest() [domain stats]
  ↓
BACK TO AWARENESS (next request)
```

## Current

```
INPUT → User sends message
  ↓
EXECUTIVE → ceoRuntime.execute() / ctoProgram.execute() [LLM call]
  ↓
TOOLS → Tool execution (sometimes)
  ↓
OUTPUT → Return text response

MISSING: Awareness, Understanding, Planning, Grounding,
         Verification, Replan, Reflection, Learning
```

| Loop | Type | Description |
|------|------|-------------|

| LOOP 2 | Cross-request | REFLECT → STORE(metrics) → NEXT(findSimilar → few-shot) |
| LOOP 3 | System-level | HEALTH MONITOR → CIRCUIT BREAKER → ADAPTIVE TIMEOUT → AWARENESS |

# SECTION 5 — Awareness Graph

## Flow

```
7 SOURCES (each try/catch'd):
  BusinessStateCollector → cash, branches, employees, workload, hours
  DigitalTwinProvider → revenue, expenses, margin, stock, satisfaction
  MissionEngine → active, inProgress, completed, failed
  RuntimeStateBridge → EIOS RuntimeState
  HealthMonitor → component liveness (kernel, services, DB, LLM)
  KernelHeartbeat → version, uptime, memory, threads
  RuntimeHealth → serviceHealth, degradedServices, lastIncident
        │
        ▼
UnifiedAwarenessEngine.collect()
  → Aggregates all 7 → UnifiedAwareness { business, operational, ... }
        │
        ▼
AwarenessSynthesizer.synthesize()
  → Raw data → AwarenessSignal[] with priority, severity, confidence
  → AwarenessGraph (signal→risk relationships)
  → ContradictionDetector.detect()
        │
        ▼
AwarenessPrioritizer.prioritize()
  → Sort by priority → criticalSignals, warnings, ordered
  → awarenessScore (0-100) → OverallHealth → nextAttention
  → BusinessSituation { summary, riskLevel, trend, focus }
  → SystemSituation { summary, health, degradedServices }
        │
        ▼
AwarenessBrief { summary, overallHealth, awarenessScore, signals, ... }
        │
        ▼
CONSUMERS:
  UnderstandingEngine (for LLM prompt context) ✓
  RuntimeContext.awareness (for Executive decision) — DEAD
```
