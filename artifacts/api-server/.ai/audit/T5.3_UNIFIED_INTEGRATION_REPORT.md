## 5. Synchronization Flow

```
Decision Made
    ↓
EIOS Observer:
  ├── ingestEpisode() → KnowledgeBase
  ├── recordOutcome() → Knowledge Platform (confidence adjust)
  └── provideFeedback() → UnifiedLearningLayer
                              ├── KP: recordOutcome() for all domain blocks
                              └── (Council: passive — stats enrich next session)

Every 6h: Cross-Engine Sync
    ↓
UnifiedLearningLayer.synchronize()
    ├── Council patterns → KP procedural blocks (pattern → procedure)
    └── KP confirmed count → Org Learning coherence check

Every Hourly: KP Maintenance
    ↓
processEpisodeOutcomes() → batch confidence adjustment
runMaintenance() → promotion + deprecation + archive

Every Decision:
UnifiedLearningLayer.retrieve() called
    ├── Org Learning (knowledgeGraph + memoryIndex)
    ├── KP Learning (episode + semantic + procedural blocks)
    ├── Council Learning (past outcomes)
    ├── Executive Memory (past decisions)
    ├── Deduplication (token similarity > 0.6 = merge)
    ├── Conflict Resolution (highest confidence wins)
    └── Ranking (confidence * 0.4 + freshness * 0.3 + importance * 0.3)
```
