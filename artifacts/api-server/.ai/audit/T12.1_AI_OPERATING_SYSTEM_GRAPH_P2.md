# SECTION 6 — Cognitive Graph

## How the AI Should Think

```
USER MESSAGE: "What's our cash position?"
  │
  ▼
AWARENESS: System state before thinking
  "Cash low, 3 branches degraded, revenue declining since Tuesday"
  │
  ▼
UNDERSTAND: What does the user want?
  Intent: "inquiry"
  Domain: "finance"
  Entities: ["cash", "position"]
  SubIntent: "financial_reporting"
  Confidence: 0.91
  │
  ▼
PLAN: What data do I need?
  Task 1: BUSINESS_METRICS → operational data (revenue, expenses)
  Task 2: KNOWLEDGE_BLOCK → financial knowledge
  Task 3: MEMORY → past financial queries
  │
  ▼
GROUND: Fetch the data
  OperationalTruthProvider: { revenue: 125000, expenses: 98000 }
  KnowledgeProvider: { cash_ratio_calculation: "current_assets / current_liabilities" }
  MemoryProvider: { past_query: "user asked about cash last week" }
  │
  ▼
VERIFY: Is the data correct and sufficient?
  domain_availability: ✓ (finance domain supported)
  entity_verification: ✓ (cash and position resolved)
  operational_data: ✓ (financial data present)
  Confidence: 0.88
  │
  ▼ (0.88 >= 0.75 → no replan needed)
  │
  ▼
DECIDE: Executive makes informed decision
  ExecutiveContext = {
    domain: "finance",
    confidence: { overall: 0.88 },
    awareness: { businessRisk: "medium", systemHealth: "degraded" },
    knowledge: [...],
    operational: { context: { revenue: 125000, expenses: 98000 } }
  }
  → CFO.decide(executiveContext)
  → Decision: { action: "report", reasoning: "Cash ratio is 1.28...", confidence: 0.92 }
  │
  ▼
EXECUTION: (optional, if tools needed)
  → No tool execution needed for simple query
  │
  ▼
REFLECTION: What did we learn?
  Pattern: "user asks about financial state in morning hours"
  Success: "high confidence (0.88), no replan needed"
  │
  ▼
LEARNING: Record for future
  MetricsStore.recordRequest(domain:"finance", confidence:0.88, degraded:false)
```

## Cognitive Nodes

| Node | Input | Output | LLM Call? | Owner |
|------|-------|--------|-----------|-------|
| Awareness | 7 external sources | AwarenessBrief | NO | RIC |
| Understanding | UserMessage + AwarenessBrief | UnderstandingResult | YES | RIC |
| Planning | UnderstandingResult + PastPlanMemory | RetrievalPlan | YES | RIC |
| Grounding | RetrievalPlan | GroundingResult | NO | RIC |
| Verification | Understanding + Plan + Grounding | VerificationResult | NO | RIC |
| Confidence | Understanding + Grounding + Verification | OverallConfidence | NO | RIC |
| Replan | PreviousPlan + Verification | RetrievalPlan | YES (or algorithmic) | RIC |
| Decision | ExecutiveContext | ExecutiveDecision | YES (compact) | Executive |
| Execution | ExecutiveDecision | ExecutionResult | NO (tools) | Tool Layer |
| Reflection | ExecutionResult + Metrics | Reflection | NO | RIC |
| Learning | Reflection | Updated Metrics | NO | RIC |

**Total LLM calls per request (target):** 3 (Understanding + Planning + Executive Decision)

**Total LLM calls per request (current):** 1 (Executive does everything in one LLM call)

**Trade-off:** +2 LLM calls for structured reasoning, verification, and context. Net quality improvement.

# SECTION 7 — RuntimeContext Graph

## Full Structure

```
RuntimeContext (immutable, frozen via deepFreeze)
│
├── version: "1.0"
├── contractId: UUID
├── createdAt: timestamp
├── degraded: boolean
├── degradedReason?: string
│
├── intelligence (from UnderstandingEngine)
│   ├── goal: string
│   ├── intent: string
│   ├── subIntent: string
│   ├── domain: { primary, secondary[] }
│   ├── entities: Entity[]
│   ├── reasoning: { intentRationale, domainRationale, entityRationale, alternatives }
│   ├── thinkingMode: "fast" | "balanced" | "deep"
│   ├── urgency: "low" | "medium" | "high"
│   ├── risk: { level, factors[], requiresApproval }
│   └── confidence: number
│
├── planning (from RetrievalPlanner)
│   ├── executionPlan: ExecutionStep[]
│   ├── suggestedTools: ToolSuggestion[]
│   ├── recommendedStrategy: string
│   └── expectedOutput: string
│
├── grounding (from GroundingLayer)
│   ├── operational: OperationalData[]
│   ├── memory: MemoryContext
│   ├── knowledge: KnowledgeBlock[]
│   ├── repository: FileContent[]
│   ├── metadata: MetadataNode[]
│   ├── requiredTruth: RetrievalTask[]
│   ├── retrievedTruth: GroundingResult[]
│   └── missingTruth: string[]
│
├── verification (from VerificationEngine)
│   ├── results: VerificationResult
│   └── explainability: { whyDomain, whyTool, whyRepository, whyMemory,
│                         whyConfidence, whyPlanning }
│
├── awareness (from AwarenessBrief, via RuntimeContextBuilder)
│   ├── summary: string
│   ├── overallHealth: string
│   ├── overallConfidence: number
│   ├── awarenessScore: number
│   ├── nextAttention: string
│   ├── businessSituation: { summary, riskLevel, trend, focus }
│   ├── systemSituation: { summary, health, degradedServices[], runtimeState }
│   ├── criticalSignalCount: number
│   └── warningCount: number
│
├── refinementHistory (from Replan Loop)
│   └── RefinementEntry[]
│       ├── iteration: number
│       ├── confidenceBefore: number
│       ├── confidenceAfter: number
│       ├── taskCountBefore: number
│       ├── taskCountAfter: number
│       ├── changedCapabilities: string[]
│       ├── failedChecks: string[]
│       ├── resolvedChecks: string[]
│       └── triggeredBy: string
│
└── runtime (from PipelineTracer + ConfidenceAggregator)
    ├── trace: RuntimeTrace
    ├── evidence: Evidence[]
    ├── budget: RuntimeBudget
    ├── confidence: OverallConfidence { reasoning, grounding, verification,
                                        adjustment, overall, weakAreas[] }
    └── reasoningTrace: TraceEntry[]
```

# SECTION 8 — Data Ownership Graph

## Single Ownership Principle

```
RUNTIME INTELLIGENCE CORE (RIC) — OWNS:
│
├── Reasoning (UnderstandingEngine)
│   ├── Intent (determined by LLM, validated by fallback)
│   ├── Domain (primary + secondary, verified)
│   ├── Entities (extracted, validated)
│   └── Risk Assessment (by LLM)
│
├── Planning (RetrievalPlanner)
│   ├── ExecutionPlan (capability-based tasks)
│   ├── ToolSuggestions (from CapabilityRouter)
│   ├── Dependency Graph (task ordering)
│   └── PastPlanMemory (in-memory store)
│
├── Grounding (GroundingLayer)
│   ├── OperationalTruth (from OperationalTruthProvider)
│   ├── MemoryEntries (from MemoryProvider)
│   ├── KnowledgeBlocks (from KnowledgeProvider)
│   ├── FileContents (from RepositoryProvider)
│   └── MetadataNodes (from MetadataProvider)
│
├── Verification (VerificationEngine)
│   ├── Rule Results (pass/fail per check)
│   ├── Contradictions (between sources)
│   └── Confidence Adjustment (from VerificationResult)
│
├── Awareness (UnifiedAwarenessEngine)
│   ├── UnifiedAwareness (aggregated state)
│   ├── AwarenessSignals (prioritized)
│   └── AwarenessBrief (compact for consumers)
│
├── Context (RuntimeContextBuilder)
│   └── RuntimeContext (single immutable contract)
│
├── Learning (MetricsStore + ReflectionEngine)
│   ├── Domain Metrics (confidence trends)
│   ├── Provider Metrics (failure rates)
│   └── Reflection Patterns (cross-request)
│
└── CircuitBreaker (GroundingLayer)
    └── Provider Circuit States (CLOSED/OPEN/HALF_OPEN)


EXECUTIVE RUNTIME — OWNS:
│
├── Persona (CEO | CTO | CFO | COO | CMO | CAIO | CHRO | CKO)
├── Domain-Specific Decision (ExecutiveDecision)
│   ├── Action: what to do
│   ├── Reasoning: why
│   └── Confidence: how sure
└── Execution Orchestration
    └── Tool Call Sequencing (if multi-step)


EIOS RUNTIME — OWNS:
│
├── Mission (MissionEngine)
│   ├── Mission Contract
│   ├── Mission State Machine
│   └── Mission History
│
├── Runtime Lifecycle
│   ├── Pipeline Stages
│   ├── Stage DAG
│   └── Execution Order
│
├── Governance
│   ├── Security Policies
│   ├── Compliance Rules
│   └── Audit Trail
│
└── Learning Integration
    └── Cross-Executive Learning


EXECUTION LAYER — OWNS:
│
├── LLM Communication (llm-adapter)
│   └── DeepSeek HTTP API calls
│
├── Tool Execution (tool-adapter)
│   ├── Filesystem operations
│   ├── GitHub API calls
│   ├── SSH commands
│   └── Database queries
│
└── Communication (CommunicationProvider)
    └── Notifications, alerts
```
