## Before vs After Architecture

### BEFORE (T6.6)

```
CFO.execute()
  ├── understand() → spec
  ├── Verification + Governance
  ├── CKO Consult
  ├── memoryProvider.read()
  ├── CognitiveEngine
  ├── PlanProvider.getAll()
  ├── KnowledgeProvider.searchAll()        ← Direct KP access
  ├── getBranchContext()                   ← Direct SQL (db.select.branchesTable)
  ├── ExecutionPipeline.execute(LOCAL_TOOLS)  ← Tool Runtime
  └── Response
```

### AFTER (T6.7)

```
CFO.execute()
  ├── understand() → spec
  ├── Verification + Governance
  ├── CKO Consult
  ├── memoryProvider.read()
  ├── CognitiveEngine
  ├── OperationalTruthProvider.getFinanceContext()  ← SINGLE provider call
  │     └── (internally calls tools, parses, normalizes)
  ├── OperationalTruthProvider.getBranchContextString()  ← via provider
  ├── callDeepSeek(prompt + FinanceContext)   ← No tools
  └── Response
```

## FinanceContext Specification

```
FinanceContext (from OperationalTruthProvider.getFinanceContext())
  ├── finance.revenue: number
  ├── finance.totalOrders: number
  ├── finance.averageOrderValue: number
  ├── finance.totalExpenses: number
  ├── finance.grossProfit: number
  ├── finance.grossMargin: number
  ├── finance.period: string
  ├── finance.branchId: number
  ├── topProducts: {name, sold, revenue}[]
  ├── branches: {id, name, location}[]
  └── confidence, missingDomains, errors, timestamp
```
