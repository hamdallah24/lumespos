# Executive Constitution

The Executive Constitution defines the fundamental principles governing
all Executive Runtime behavior.

1. Runtime Core (EIOS v4.1) is FROZEN — no modifications.
2. All executives operate through ExecutiveDispatchRegistry.
3. No executive may access eios-runtime/internal/*.
4. Foundation is the single source of truth for all directives.
5. Knowledge System provides structured knowledge to executives.
6. Cognitive Engine provides reasoning before prompt assembly.
7. All decisions must be traceable end-to-end.
8. Evidence must support all executive decisions.
9. Confidence must be reported with every recommendation.
10. Memory Engine (future) will persist runtime experience.
